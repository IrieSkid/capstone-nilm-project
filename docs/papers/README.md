# Papers and requirements

- `software-based-nilm-paper.docx` is the editable project-paper source currently
  available in this repository.
- `software-based-nilm-paper-latest.pdf` is the latest exported paper received
  before the proposed shift toward an engineering monitoring application.
- `functional-and-non-functional-requirements.docx` contains the earlier system
  requirements.

These documents are retained for traceability. They should not be treated as the
final specification until the multi-PZEM topology and revised application scope
have been approved.
